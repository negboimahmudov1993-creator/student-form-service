# Сервис создания форм отклика для студентов

Автономный сервис для карьерной платформы, позволяющий менеджерам конструировать формы откликов на стажировки и мероприятия, публиковать их по уникальным ссылкам и собирать ответы студентов с аналитикой конверсии.

## 🚀 Быстрый запуск

Проект запускается двумя стандартными командами:

```bash
npm install
npm start
```

После запуска сервис доступен по адресу: **http://localhost:3000** (или через порт, переданный в переменной окружения `PORT`).

---

## 🛠 Технологический стек

- **Runtime**: Node.js 20+
- **Backend-фреймворк**: Express
- **Шаблонизатор**: EJS (шаблоны в директории `views/`)
- **Стилизация**: Tailwind CSS (подключен через официальный CDN `<script src="https://cdn.tailwindcss.com"></script>`)
- **База данных**: Локальная JSON-база `db.json` в корне проекта (автономная, не требует внешних СУБД или API-ключей, устойчивая к перезапускам)
- **Шрифт**: Inter

## 📋 Реализованный функционал и маршруты

### 1. Панель менеджера (`/admin`)
- **Сводная статистика**:
  - Всего активных форм
  - Общее количество полученных откликов
  - Общее количество просмотров
  - Средняя конверсия заполнения
- **Список всех форм и разграничение доступа менеджеров**:
  - Категория, дата создания, количество вопросов и **ответственный менеджер/автор** (с фильтрацией «Все менеджеры» / конкретный менеджер)
  - Статистика по конкретной форме: просмотры, отклики, конверсия (%)
  - **Управление статусом анкеты**: мгновенная приостановка / возобновление приема откликов в 1 клик (без удаления формы)
  - Быстрое копирование ссылки на форму в один клик с визуальным уведомлением
  - Переход к публичной странице формы
  - Кнопка перехода к ответам
  
- **Создание новой формы (`/admin/forms/new`)**:
  - Название, описание и категория формы
  - Быстрые шаблоны в один клик: «Стажировка», «Мероприятие», «Опрос»
  - Динамический конструктор вопросов с выбором типа:
    - *Короткий текст*
    - *Развернутый ответ (textarea)*
    - *Email*
    - *Выпадающий список (Select)*
    - *Один из списка (Radio)*
    - *Несколько из списка (Checkboxes)*
    - *Число (курс, стаж)*
  - Настройка обязательности каждого вопроса
  - Изменение порядка вопросов (вверх/вниз) и удаление вопросов
  - Управление вариантами ответов

### 2. Просмотр ответов студентов (`/admin/forms/:id/responses`)
- Сводная карточка аналитики (просмотры, успешные отклики, конверсия)
- **Аналитика заполняемости по каждому вопросу** — решает проблему понимания, на каких вопросах студенты бросают анкету
- Таблица полученных откликов с датой/временем и превью ключевых данных
- Модальное окно с детальным просмотром полной анкеты студента
- **Экспорт в CSV** (`/admin/forms/:id/export.csv`) с кодировкой UTF-8 BOM для корректного открытия в Excel

### 3. Публичная форма студента (`/forms/:id`)
- Минималистичный дизайн в стиле SaaS (Tally / Notion)
- Фон `bg-slate-50`, карточки `bg-white`, акцентный цвет кнопок Indigo `bg-indigo-600`
- Динамический прогресс-бар («20% заполнено • 1/5 вопросов»), мотивирующий студента завершить заполнение
- Понятные подсказки и валидация обязательных полей
- Защита от повторной отправки (состояние загрузки)

### 4. Экран подтверждения (`/forms/:id/success`)
- Экран «Спасибо за отклик!»
- Подтверждение получения анкеты, номер отклика и дата/время
- Информация о дальнейших шагах (связь в течение 2-3 рабочих дней)
- Кнопка повторной отправки или перехода в панель управления

## 📂 Структура проекта

```text
├── db.json                 # Локальная база данных (формы и ответы)
├── package.json            # Зависимости и скрипты запуска
├── server.js               # Express-сервер, маршрутизация и логика БД
├── README.md               # Документация проекта
└── views/                  # EJS-шаблоны страниц
    ├── partials/
    │   ├── header.ejs      # Общий header, шрифты, Tailwind CDN
    │   └── footer.ejs      # Общий footer и toast-уведомления
    ├── admin.ejs           # Панель менеджера со списком форм и метриками
    ├── new_form.ejs        # Визуальный конструктор форм с шаблонами
    ├── form_responses.ejs  # Просмотр ответов, аналитика и экспорт
    ├── form_view.ejs       # Публичная форма студента (Tally/Notion стиль)
    └── thank_you.ejs       # Экран "Спасибо за отклик!"
```
