# Инструкция по запуску и тестированию проекта (TESTING.md)

Сервис создания форм откликов для студентов и стажировок.

---

## ⚡ 1. Быстрый запуск

Для запуска проекта требуются только **Node.js (v20+)** и стандартные команды:

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера
npm start
```

Сервер автоматически запустится на порту **3000** (или через переменную окружения `PORT`).

---

## 🌐 2. Ссылки и маршруты приложения

После запуска сервис доступен в браузере:

| Маршрут | Описание | Доступ |
|---|---|---|
| **`http://localhost:3000/admin`** | **Панель менеджера** (дашборд, список всех форм, фильтры, аналитика конверсии) | Без авторизации (по ТЗ) |
| **`http://localhost:3000/admin/forms/new`** | **Визуальный конструктор форм** (добавление вопросов, шаблоны, дедлайн, автор) | Доступен из админки |
| **`http://localhost:3000/admin/forms/form-intern-2026/edit`** | **Редактирование формы** (изменение названия, описания, вопросов, вариантов) | Доступен из карточки формы |
| **`http://localhost:3000/admin/forms/form-intern-2026/responses`** | **Ответы студентов** (поиск, фильтр по статусам, просмотр анкеты, экспорт в CSV) | Доступен из карточки формы |
| **`http://localhost:3000/forms/form-intern-2026`** | **Публичная страница формы** (для заполнения студентом) | Публичная ссылка |
| **`http://localhost:3000/`** | Главная страница (автоматический редирект на `/admin`) | Публично |

---

## 🗑 3. Управление формами и удаление

- Удаление форм является прямым и свободным для менеджера в панели управления `/admin` (кнопка корзины в карточке формы).
- Удаление происходит напрямую без ввода PIN-кода и без блокирующих браузерных диалогов (также поддерживается безопасная работа в iframe-окружении).
- При удалении формы связанные отклики автоматически очищаются из `db.json`.
- Также доступно быстрое удаление отдельных откликов кандидатов в таблице `/admin/forms/:id/responses`.
- Публичные страницы форм для студентов (`/forms/:id` и `/forms/:id/success`) изолированы: они не содержат ссылок на панель управления менеджера (`/admin`).

## 🧪 4. Сценарии для быстрой проверки функционала

### Сценарий А: Просмотр откликов, поиск и статусы кандидатов
1. Откройте **`http://localhost:3000/admin`**.
2. В карточке формы «Отклик на оплачиваемую стажировку» нажмите синюю кнопку **«Ответы»**.
3. **Поиск**: введите в поле поиска имя (например, `Александр` или `Екатерина`) или технологию — таблица отфильтруется мгновенно на лету.
4. **Фильтр по статусу**: выберите в выпадающем списке `🟢 Приглашены` или `🔵 На рассмотрении`.
5. **Смена статуса кандидата**: измените статус студента в выпадающем списке — статус **автоматически сохранится в `db.json`** без перезагрузки страницы (с всплывающим уведомлением).
6. **Экспорт**: нажмите **«Экспорт в CSV»** — скачается корректный CSV-файл для Excel.

### Сценарий Б: Заполнение формы студентом
1. Откройте публичную форму **`http://localhost:3000/forms/form-intern-2026`**.
2. Обратите внимание на:
   - Форматирование описания вакансии (**жирный шрифт**, списки преимуществ, ссылка).
   - Индикатор прогресса вверху («25% заполнено»).
   - Бейдж дедлайна.
3. Заполните поля и нажмите **«Отправить отклик»**.
4. Вы увидите экран «Спасибо за отклик!» с сгенерированным ID отклика.
5. Вернитесь в админку — отклик уже отображается в таблице с начальным статусом `🟡 Новый`.

### Сценарий В: Конструктор новой формы
1. В админке нажмите **«Создать форму»** (`/admin/forms/new`).
2. Нажмите один из быстрых шаблонов («Стажировка» или «Мероприятие»).
3. Задайте дедлайн и имя куратора, настройте вопросы.
4. Нажмите **«Создать и опубликовать форму»** — ссылка появится в общем списке.

### Сценарий Г: Дедлайн и пауза приема
- В админке можно в 1 клик нажать кнопку **«Пауза»** — прием откликов мгновенно блокируется с выводом предупреждения для студентов.
- Если у формы наступил дедлайн, студенты видят экран: *«Прием откликов на эту вакансию завершен»*, а отправка формы надежно блокируется на клиенте и сервере.

## 💾 5. Локальная база данных

- Данные хранятся в корневом файле **`db.json`**.
- Никаких внешних СУБД, Docker или API-ключей не требуется.
- Проект полностью автономен.
